두 값을 붙여넣고 인증값을 복사하세요

이 HTML 파일을 내려받아 브라우저에서 직접 여세요. 인터넷 연결 없이 사용할 수 있습니다. 외부 변환 사이트나 명령어는 필요하지 않습니다.

  1. 본인의 PayPal Sandbox 앱에서 Client ID와 Client Secret을 각각 복사해 아래에 붙여넣으세요.
  2. ‘인증값 만들기’를 누른 다음 ‘인증값 복사’를 누르세요. 자동으로 복사하지 않습니다.
  3. 환경의 보안 입력 화면에서 PAYPAL_OAUTH_BASIC_AUTH_HEADER Network secret 값으로 직접 붙여넣으세요. 복사된 값에 Basic을 더하거나 다시 인코딩하지 마세요. 이 모드에서는 PAYPAL_CLIENT_ID와 PAYPAL_CLIENT_SECRET을 함께 설정하지 마세요.
  4. 완료 후 ‘모두 지우기’를 누르고 이 탭을 닫으세요. 대화·로그·공개 저장소에는 붙여넣지 마세요.

입력 정책: 각 값은 1~4096자의 ASCII 표시 문자만 허용합니다. 공백(앞뒤·중간 포함), 탭, 줄바꿈, 제어문자, 한글 등 비 ASCII 문자는 거부하며 자동 제거·변환하지 않습니다. Client ID에는 콜론(:)을 쓸 수 없습니다. Secret의 콜론은 그대로 포함합니다. 잘못된 붙여넣기는 해당 칸을 비우고 오류를 알립니다.

입력값과 결과는 이 페이지의 메모리에서만 다룹니다.

직접 선택해 복사하세요

이 영역에는 비밀 인증값이 보입니다. Ctrl+C / ⌘C 또는 모바일의 복사 메뉴를 사용하세요. 복사 후 값을 숨기거나 모두 지워 주세요.

결과는 Basic + Base64(Client ID:Client Secret) 형식입니다. Base64는 암호화가 아니며 결과도 비밀값입니다. 이 파일은 인증값의 유효성을 PayPal에 확인하지 않고, 환경 설정도 변경하지 않습니다. Cloud Network proxy 실제 연동은 별도 검증이 필요합니다.

페이지는 네트워크 요청이나 저장소·쿠키·분석 도구를 사용하지 않습니다. 지우기는 폼과 페이지가 보유한 변수를 비웁니다. 메모리의 물리적 완전 삭제를 보장하지 않으며, 이미 복사한 값은 시스템 클립보드에 남을 수 있습니다. 브라우저의 비밀번호 저장 제안은 거절하세요.
